# 하루 공부 계획표 앱

시험 과목과 남은 날짜를 입력하면 오늘부터 시험 전날까지 하루 공부량을 자동으로 나눠 주는 정적 웹 앱입니다.

## 기능

- 시험 과목과 과목별 공부량 입력
- 남은 날짜 입력
- 하루 공부량 자동 분배
- 오늘 할 일 표시
- 완료 체크 및 브라우저 로컬 저장

## 실행 방법

별도 빌드 없이 브라우저에서 `index.html`을 열면 됩니다. 로컬 서버로 확인하려면 다음 명령을 사용할 수 있습니다.

```bash
python3 -m http.server 8000
```

그 다음 <http://localhost:8000>으로 접속합니다.
